## 🚀 Quick Start (3 Steps)

### Step 1: Install Dependencies (2 minutes)
```bash
npm install
```

### Step 2: Add Your Photo (1 minute)
1. Create a `public` folder in the root directory
2. Add your 200×200px photo as `public/profile.jpg`
3. Open `components/ProfileCard.jsx`
4. Replace lines 28-32 with:
```jsx
<img 
  src="/profile.jpg" 
  alt="Varsha S" 
  className="w-full h-full object-cover"
/>
```

### Step 3: Test Locally (1 minute)
```bash
npm run dev
```
Open http://localhost:3000 in your browser!

## 🎯 Before Deploying (5 minutes)

### Update GitHub Links
Open `sections/TradingCardsSection.jsx` and replace all placeholder GitHub links:


### Optional Customizations
- Update bio in `components/ProfileCard.jsx` (line 38)
- Modify skills badges (line 44)
- Add/remove projects in `sections/TradingCardsSection.jsx`

## 🌐 Deploy (5 minutes)

### Option A: Vercel (Easiest)
1. Push code to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Click "Import Project"
4. Select your repo
5. Click "Deploy"
6. Done! 🎉

### Option B: Netlify
1. Run `npm run build`
2. Go to [netlify.com](https://netlify.com)
3. Drag the `dist` folder
4. Done! 🎉

## 🐛 Having Issues?

**Blank page?**
- Check browser console (F12) for errors
- Verify all files are in correct locations

**Styles not working?**
- Run `npm install` again
- Check `postcss.config.js` exists

**Images not loading?**
- Verify photo is in `public/` folder
- Check file path is correct

**Build fails?**
- Delete `node_modules` folder
- Run `npm install` again
- Try `npm run build` again
